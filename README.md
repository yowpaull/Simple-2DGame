# Simple 2D Game 🎮

A 2D game created using **Unity**.  
This project demonstrates core 2D gameplay mechanics, scenes, and assets built with the Unity game engine.

---

## 🛠️ Built With
- **Unity** (2D)
- **C#**
- Unity Package Manager

---

## 📂 Project Structure
This repository contains only the essential Unity project files:
Generated folders such as `Library`, `Temp`, and `Build` are excluded using `.gitignore`.

---

## ▶️ How to Open the Project
1. Install **Unity Hub**
2. Make sure you have the correct Unity version installed
3. Open Unity Hub → **Open Project**
4. Select this project’s root folder
5. Press **Play** in the Unity Editor

---

- 2D gameplay

- Custom assets and scenes
